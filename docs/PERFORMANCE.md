# 1.3.7 性能说明

2026-10-05，Apple M5、macOS 27、Retina。CPU 100% 表示一个核心；GPU 时间按应用组统计，不是全机 GPU 利用率。

## 相同背景窗口对照

同一渲染器、模拟音量、260×180 点渲染区和 1600×500 背景；背景 30Hz、绘制回调约 60Hz。两轮以相反顺序测试，稳定区间 12 秒。

|路径|第一轮 CPU|第二轮 CPU|按时长加权|
|---|---:|---:|---:|
|旧图片转换与上传|23.72%|15.24%|19.48%|
|直接映射 Metal 纹理|7.78%|7.36%|7.57%|

配对减少 51.7%–67.2%，加权约 61.1%。不包含实际屏幕采集、录音、识别和共享桌面合成，不能当成电池续航增幅。

同相位原生 Metal 输出校验最大 8 位色差 1，轮廓 alpha 一致。32 项回归检查通过。

## 实际静默 Fn 录音

外观预览关闭，静置→按住 Fn→松开。稳定录音区间应用 CPU 11.66%（峰值 13.81%）、RSS 228.08 MiB、应用组 GPU 时间 20.56 ms/s，松开后 CPU/GPU 回落。热压力为 Nominal。全机芯片估算增量约 2.10 W，包括其他应用和共享服务，不是本应用独占耗电。

记录含 109 个完整功耗样本与 112 个进程样本，覆盖三阶段；采集提前结束且缺少退出状态文件，原因未核实。连续说话的识别/粘贴、长时间泄漏与电池续航未在这轮验证。原始本机记录用于生成以上汇总，随后按维护者要求清理；未上传个人进程清单或机器遥测。

## 与传统 Siri 的参照

本机实际可用的是传统 Siri，每次约 5–6 秒后收起。探索性活跃样本：本版 CPU 12.28%、GPU 21.86 ms/s；传统 Siri 界面及辅助进程 CPU 12.10%、GPU 35.63 ms/s。功能、时长、状态与后台活动不完全一致，且采样工具报告诊断警告，仅作粗略参照，不报告精确性能优势或官方同级。

系统中存在名为 Siri AI 的组件不代表新版功能可用。没有新版 Siri AI 动效的同机实测，无法计算与其性能差距。
