# VoiceInput 中文使用说明

这是基于 yetone/voice-input-dist（上游提交 98c9ac5）的本机改进版，保留 Apple Speech 实时语音识别、Fn 按住录音和底部胶囊悬浮窗。原项目：https://github.com/yetone/voice-input-src ，实际 Swift 文件来自 https://github.com/yetone/voice-input-dist 。许可证保留上游 MIT 版权声明。

项目版本：1.3.11。源码位于本仓库。

本版修复录音启动时音频设备异常导致应用退出的问题；每次录音重新创建采集引擎。录音中设备变化时会停止该次采集，可松开 Fn 后重新按住重试。

安装版首次运行会登记系统登录项；顶部麦克风菜单的「登录时自动启动」可关闭或开启。若显示「待系统允许」，到「登录项设置…」确认；关闭后不会在下次启动时自动打开。

日常打开：在“应用程序”里打开 VoiceInput。它只在屏幕顶部显示一个麦克风图标，没有 Dock 图标。

## 第一次使用

1. 点顶部麦克风图标 → **检查权限并开启…**。
2. 系统询问时允许麦克风和语音识别。
3. 在 **系统设置 → 隐私与安全性 → 辅助功能** 中，用“+”添加 `/Applications/VoiceInput.app`，打开开关。若系统还提示输入监控，也允许 VoiceInput。
4. 回到顶部麦克风菜单，再点 **检查权限并开启…**。显示“按住 Fn 说话，松开输入”即已开启。
5. 点进备忘录或任意输入框，**按住左下角 Fn/🌐 说话，松开**。录音时显示胶囊和实时声音波形。

默认简体中文；在“识别语言”可切换英语、繁体中文、日语或韩语。建议第一次试说：“你好，这是一条语音输入测试。”

如果 Fn 仍出现表情窗口，在 **系统设置 → 键盘 → 按下 🌐 键以** 中选择 **不执行任何操作**。

处理期间请保持原来的输入框。若窗口或焦点变化，软件会保留结果，点击菜单 **复制上次识别结果** 后手动粘贴。模拟粘贴无法检查所有应用是否实际接收了文字；遇到没有输入的应用也可这样取回结果。

本版防止重复粘贴和旧结果串入新录音，粘贴后恢复剪贴板中的多种数据（包括图片、文件）。如果你在这期间复制了新内容，会保留新内容。不要在处理期间退出软件，否则来不及执行剪贴板恢复。

## 录音动效（1.3.7）

顶部麦克风菜单 → **外观设置…**，在 **Siri 光波 / 厚玻璃胶囊** 中选择。Siri 光波采用原生 Metal 绘制：按住 Fn 时玻璃展开，说话时彩色光波增强，安静时压成纤细彩色光芯，松开后收回并淡出。两侧玻璃反光随光波相位和音量变化。设置窗口、桌面预览与录音浮层共用同一渲染器。松开后的文字输入仍等待浮层退场完成。

Siri 光波基于社区项目 https://github.com/neeldedkawala/ios-siri-animation 的 MIT 公式移植，并非苹果内部 Siri 渲染器；第三方许可证在应用资源的 `VoiceInput_VoiceInput.bundle/Resources/THIRD_PARTY_LICENSE` 中保留。新风格退场约0.54秒，旧厚玻璃约0.16秒；没有改变录音与中文输入操作。

Liquid Glass 调节玻璃透光程度，联动幅度调节音量驱动的光波幅度；背景折射仍需原有屏幕录制许可。无背景采集时 Siri 光波仍显示玻璃和光波，使用中性的玻璃背景；它不会自动切回旧厚玻璃。

Siri 光波使用连续流动的彩色光片，光芯、透光和曲面反射共同变化。1.3.11 按下 Fn 时先从零尺寸放大黑色小胶囊，约0.10秒开始同步展开，约0.48秒展开完成，动画不额外等待录音启动；松开 Fn 时停止接收音频，光片收细、玻璃收成小胶囊，同时逐渐缩小至消失，完整退场约0.54秒后交还输入焦点；识别结果就绪后才输入。预览和实际录音共用渲染器，旧厚玻璃仍可切换。Siri 光波下方不再显示识别文字或状态字幕，松开 Fn 后仍将识别结果输入原输入框。

## 厚玻璃胶囊外观

顶部麦克风菜单 → **外观设置…**，可实时预览并调节：

- **Liquid Glass**：向左更通透，向右更浓厚；文字和波形始终保持清晰；玻璃浓度控制玻璃体的透光程度。
- **联动幅度**：控制录音时外壳随声音伸缩的程度；设为 0 可保持外壳稳定。
- **通透 / 柔和**：切换玻璃材质。
- **桌面预览**：直接显示与 Fn 录音共用的悬浮胶囊，不调用麦克风；可在不同背景上调节外观。按 Esc 返回设置；开始 Fn 录音或关闭设置窗口时自动结束预览。

玻璃体没有独立的白色高光圈、描边或外轮廓，通过背景曲面折射与玻璃体内部柔光呈现形状；波形和显示文字作为局部光源，在上下曲面形成柔和、压缩的倒影。波形反射随音量呼吸，文字保持清晰，中心更加通透。窗口内预览、桌面预览和 Fn 录音共用同一套绘制；等待背景画面时光源仍可显示。录音期间胶囊沿用临时接收键盘焦点的流程；松开 Fn 后约 0.16 秒平滑淡出，再交还原输入窗口。文字输入会等待退场完成；识别和纠错状态显示在菜单栏。原应用不会被切换。

设置自动保存。预览使用模拟声音；实际录音会跟随麦克风音量联动。开启背景折射时使用自定义曲面玻璃，关闭或捕获不可用时使用系统磨砂材质；系统的「减少动态效果」「降低透明度」设置同样生效。隐藏胶囊和关闭外观窗口后，动画停止。

macOS 27 将原先的「辅助功能」权限入口更名为 **设备控制和数据访问**。本机签名更新后如果出现「开关已开但仍未授权」，请退出 VoiceInput，从权限列表移除旧项，再用「+」添加 `/Applications/VoiceInput.app`，然后重新打开。

## 以后再接大模型

现在 **大模型纠错默认关闭**，不需要 API 密钥即可使用 Apple 语音识别。

以后点 **大模型纠错 → 设置…**，填写：

- **API 地址**：服务商提供的 OpenAI 兼容基础地址，通常以 `/v1` 结尾。不要填写网页聊天地址，也不要重复附加 `/chat/completions`。
- **API 密钥**：服务商的 API 密钥，保存在 macOS 钥匙串。聊天会员不一定包含 API 额度。
- **模型名称**：服务商文档列出的准确模型标识。

点 **测试连接** 验证，再 **保存**，最后在菜单点 **启用纠错**。测试使用当前填写的内容，单独测试不会保存密钥。清空密钥后点保存，会删除已保存的密钥并关闭纠错。

纠错只修复明确的识别错误和中英混杂术语，仍可能误改；不是准确率保证。接口失败或超过 15 秒时使用原始识别文字。Apple 语音识别可能依赖网络/Apple 服务，本应用没有强制离线识别；开启大模型后，识别文字还会发送到你填写的服务商，录音不会发送给大模型。

## 构建

需要 Xcode/Swift，macOS 14+。在源码目录执行：

```sh
make build    # 构建并进行本机 ad-hoc 签名，产物在 .build/VoiceInput.app
make run      # 构建后打开
make install  # 安装到应用程序；若目标已存在会停止，避免覆盖
make test     # 回归检查
make clean    # 清理构建产物
```

这是本机签名，不是 Apple 开发者证书签名或公证。重新构建换版后，系统可能需要重新确认权限。

### 背景折射

外观设置中的「背景折射」需要另行允许屏幕录制权限。开启后，胶囊显示期间以 30 帧/秒读取背后的一小条画面，排除 VoiceInput 自身窗口，使用公开的 Core Image/Metal 接口模拟曲面边缘折射。画面只用于本机内存中的即时绘制，不录制系统声音、不保存文件、不上传。首次画面由单帧接口与连续采集共同准备；连续采集意外中断时临时使用单帧刷新，不会切回旧材质。胶囊退出后停止读取；无权限、捕获失败或系统启用降低透明度时保留正常录音与系统磨砂材质。窗口内的壁纸演示不需要屏幕录制权限。

厚玻璃方案使用曲面法线和空气到玻璃的折射方向，将变形集中在曲面边缘：中心保持通透稳定，边缘明显拉伸、压缩，不在最外沿收回变形。初次选择厚玻璃时应用 19% 玻璃浓度、24 折射强度；之后的手动调整会保留。当前采用用户选定的「厚玻璃 + 波形与文字光源」：局部柔光与玻璃曲面一起变化，不添加独立亮圈或描边。它是公开接口实现的自定义模拟，并非苹果内部控制中心渲染器。

「折射强度」滑块可独立调节背景弯曲和压缩幅度；不影响胶囊内的文字、波形或玻璃浓度。
